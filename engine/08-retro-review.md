# Retro review 文体约束

这一段会原样拼进两处 prompt 的「输出要求」：

- 完整 weekly / biweekly 运行时的 `retro_review` 字段
- `review-cycle` 命令为单个已结束周期生成的 review

两条路径共用同一份，所以改这里会同时影响两者——这是有意的：同一个人不该因为走了哪条路径而拿到两种形状的复盘。

编辑注意：**整个文件的正文（去掉这段说明之后的部分）就是喂给模型的指令**，不要在这里写解释性文字。文件被删或清空时，程序会回退到代码内置的同一份默认值，不会静默丢掉约束。
